# TSUZURIA の企画

TSUZURIA は、友だち3〜5人で一冊の日記を順番に回す交換日記の Web アプリです。自分の番が来たら、書けるときに近況を書いて次の人へ渡します。

## どんな場面に使うか

特別な用事がなくても、友だちの普段の生活や気になっていることを少しずつ知れる場を作りたい。書く順番があると、自分から会話を切り出さなくても近況を伝えるきっかけが生まれます。すでにつながりのある友だち同士が、それぞれの都合に合わせて使う場面を想定しています。

書く時間の目安は一度10分以内です。読んだ人は、気持ちを伝えたいときにワンタップで反応できます。画面は罫線や余白を使い、紙の交換日記を開く雰囲気を目指しています。

## 最初に届ける体験

- 友だちを招待してグループを作り、3人そろったら作成者から順番に回し始める。
- 自分の番に下書きを保存し、書き終わったら次の人へ渡す。共有された日記は、閲覧権限がある間は自分の番を待たずに読める。
- 読んだ日記にリアクションを付け、あとから変更・取り消しができる。
- グループから退出すると、そのグループの日記へのアクセスと自分の日記の共有が止まる。
- 番が回ったときのメール通知は、必要な人が選んで利用できるようにする。実装・検証状況は [ロードマップ](roadmap.md) を参照。

最初の版はテキストの日記とリアクションを中心にします。2人用、写真添付、Web プッシュ通知、DM、ブロック、アプリ内の AI 機能、ネイティブアプリは初版の範囲外です。写真の見送りには、住所や行動範囲が伝わる可能性も考慮しています。音声入力や、一定時間後に番を飛ばす機能は検討中です。

## 閲覧範囲と利用テスト

日記を読める範囲は、現在の所属、参加した時点、日記を渡した時点から決めます。下書きは、グループに所属している作成者だけが読めます。メール通知の本文には、日記の内容を載せません。[設計判断](decisions.md)

最初は少人数の限定テストで、日記が何度回ったか、どこで止まったか、普段は話さない近況を安心して書けたかを確認します。リアクションや通知に負担を感じたかも聞きます。テスト前に、目的・期間、扱うデータ、閲覧できる人、削除方法、問い合わせ先、試作の制約を参加者へ伝えて同意を得ます。
